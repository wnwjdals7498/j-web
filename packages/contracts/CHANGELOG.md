# 변경 기록

## 0.2.1 — 2026-10-09

README의 과거 배포 미승인 안내를 현재 보수적 구현과 검증 경계로 정리했다.
0.2.0 산출물은 불변으로 보존하며 최종 소비자는 0.2.1을 고정한다.

## 0.2.0 — 2026-10-09

저장 revision 배포 요청·결과 계약을 추가했다. 기존 수동 페이지와 관리 페이지의
수동 수정은 409로 보호하고 직전 관리 버전은 비공개 UUID로 보관한다.
배포 성공과 후속 상담 origin 등록 결과는 별개다. 0.1.0은 변경하지 않는다.

0.1.0 최초 게시: 사이트·호스팅·DNS·계정/부분 실패와 페이지 콘텐츠/revision/readonly
미리보기 DTO. 도메인 규칙과 입력 상한을 공유한다. H7 배포 실행 정책은 미승인이다.
이 버전은 최초 게시 전 확장했으며 이미 게시된 버전을 덮어쓰지 않는다.
