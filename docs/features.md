# j-web 기능 목록

j-web이 제공해야 하는 기능 목록이다. 근거는 [`decisions.md`](decisions.md)의 결정 번호와 제품군 공통 결정(`j-groupware/docs/architecture.md`의 S 번호)이고, 담당 Item은 PMT 통합 project 분류 `j-web`이다. 모두 구현 전이다.

화면은 j-groupware "웹 관리" 메뉴(GW-37·38)가 그린다.

작성일: 2026-10-07
